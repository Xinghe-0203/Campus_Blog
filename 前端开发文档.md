## 2. API 基础配置

### 2.1 基础信息

| 配置项 | 值 |
| :--- | :--- |
| **API 基础地址** | `http://localhost/api` |
| **Content-Type** | `application/json` |
| **字符编码** | `UTF-8` |

### 2.2 统一响应格式

所有接口返回统一格式：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": { ... },
  "timestamp": 1714067200000
}
```

**状态码说明**：

| code | 说明 |
| :--- | :--- |
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录（需登录） |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 2.3 Axios 封装示例

```javascript
// js/api.js
const API_BASE = 'http://localhost/api';

// 创建 Axios 实例
const axiosInstance = axios.create({
  baseURL: API_BASE,
  timeout: 10000,
  headers: {
    'Content-Type': 'application/json'
  }
});

// 请求拦截器：添加 Token
axiosInstance.interceptors.request.use(
  config => {
    const token = localStorage.getItem('token');
    if (token) {
      config.headers['Authorization'] = 'Bearer ' + token;
    }
    return config;
  },
  error => Promise.reject(error)
);

// 响应拦截器：统一处理错误
axiosInstance.interceptors.response.use(
  response => {
    const res = response.data;
    if (res.code !== 200) {
      // 统一错误提示
      alert(res.message || '请求失败');
      if (res.code === 401) {
        // Token 过期，跳转登录
        localStorage.removeItem('token');
        localStorage.removeItem('refreshToken');
        window.location.href = '/login.html';
      }
      return Promise.reject(res);
    }
    return res;
  },
  error => {
    alert('网络错误，请稍后重试');
    return Promise.reject(error);
  }
);

// 导出
window.api = {
  // 用户相关
  user: {
    register: (data) => axiosInstance.post('/user/register', data),
    login: (data) => axiosInstance.post('/user/login', data),
    refreshToken: () => axiosInstance.post('/user/refresh'),
    getUserById: (id) => axiosInstance.get('/user/' + id)
  },

  // 文章相关
  post: {
    create: (data) => axiosInstance.post('/post', data),
    update: (id, data) => axiosInstance.put('/post/' + id, data),
    delete: (id) => axiosInstance.delete('/post/' + id),
    getDetail: (id) => axiosInstance.get('/post/' + id),
    getList: (params) => axiosInstance.get('/post/list', { params }),
    incrementView: (id) => axiosInstance.put('/post/' + id + '/view')
  },

  // 评论相关
  comment: {
    create: (data) => axiosInstance.post('/comment', data),
    getByPostId: (postId) => axiosInstance.get('/comment/post/' + postId),
    delete: (commentId) => axiosInstance.delete('/comment/' + commentId)
  },

  // 点赞相关
  like: {
    toggle: (postId) => axiosInstance.post('/like/' + postId),
    checkStatus: (postId) => axiosInstance.get('/like/check/' + postId)
  },

  // 收藏相关
  collect: {
    toggle: (postId) => axiosInstance.post('/collect/' + postId),
    checkStatus: (postId) => axiosInstance.get('/collect/check/' + postId),
    getMyCollections: (params) => axiosInstance.get('/collect/my', { params })
  }
};
```

## 3. 接口详细文档

### 3.1 用户模块

#### 3.1.1 用户注册

```
POST /api/user/register
```

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| username | string | ✅ | 用户名（3-20字符） |
| password | string | ✅ | 密码（8-50字符，需包含大小写字母+数字/特殊字符中的3种） |
| nickname | string | ❌ | 昵称（最长30字符） |
| email | string | ❌ | 邮箱（需符合邮箱格式） |

**请求示例**：

```json
{
  "username": "zhangsan",
  "password": "Abc123!@#",
  "nickname": "张三",
  "email": "zhangsan@example.com"
}
```

**响应示例**：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "id": 1,
    "username": "zhangsan"
  },
  "timestamp": 1714067200000
}
```

**密码复杂度要求**：
- 至少8位
- 包含大小写字母、数字或特殊字符中的至少3种

---

### 5.2 Token 刷新流程

```javascript
// Token 过期时自动刷新
async function refreshTokenIfNeeded() {
  const refreshToken = localStorage.getItem('refreshToken');
  if (!refreshToken) return false;

  try {
    const res = await api.user.refreshToken();
    localStorage.setItem('token', res.data);
    return true;
  } catch (err) {
    // 刷新失败，跳转登录
    localStorage.clear();
    window.location.href = 'login.html';
    return false;
  }
}
```
